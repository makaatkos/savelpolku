# Sävelpolku

Visuaalinen musiikin teorian oppimissovellus: rytmit, sävelten nimet, asteikot ja sävellajit, intervallit, kolmisoinnut, sointuasteet, septimisoinnut, transponointi ja säveltäjät.

Avaa sovellus: https://makaatkos.github.io/savelpolku/

- Lyhyet oppitunnit kuvin ja äänin
- Treeni: loputtomasti uusia tehtäviä
- Taitotesti: kokeen harjoitus
- Edistyminen tallentuu selaimeen, ja Google-kirjautumisella se kulkee laitteelta toiselle

Sävelpolku on itsenäinen musiikin teorian harjoitussovellus.
